# She's Right · Design vote

A one-page vote on six versions of the She's Right "Today" screen (sunny day).

Live at **https://dani2906.github.io/shes-right-vote/**

- Voters tap the screens in order, favorite first, then copy their ranking and send it back.
- Paste the replies you receive into **Count the votes** at the bottom of the page. Points: 6 for 1st place down to 1 for 6th.
